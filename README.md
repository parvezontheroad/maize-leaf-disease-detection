# Maize Leaf Disease Detection

An AI-based web application for detecting maize leaf diseases using a MobileNetV2 deep learning model.

## About the Project

This project classifies maize leaf images into four categories:

- Blight
- Common Rust
- Gray Leaf Spot
- Healthy

The trained MobileNetV2 model achieved 94.30% test accuracy.

## Technologies Used

- Python
- TensorFlow / Keras
- MobileNetV2
- Flask
- HTML
- CSS
- JavaScript
- NumPy
- Pillow

## Model

The application uses transfer learning with MobileNetV2 for four-class maize leaf disease classification.

## Input

Maize leaf image.

## Output

- Predicted disease
- Prediction confidence

## Disease Classes

1. Blight
2. Common Rust
3. Gray Leaf Spot
4. Healthy
